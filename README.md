# Battery Management Enclosure Design

## Overview

This project presents the CAD design and assembly of a battery monitoring enclosure developed using Onshape. The enclosure is designed to house an LCD display, ESP32 controller, battery pack, GPS module, and IMU sensor while providing mounting features for electronic components and cable routing.

The project demonstrates enclosure design, component packaging, assembly creation, and design for manufacturability.

---

## Design Objectives

- Create a compact electronics enclosure
- Integrate an LCD display into the front housing
- Provide mounting locations for internal electronics
- Include battery storage space
- Enable cable routing between components
- Design a removable battery cover
- Assemble all components into a complete system
